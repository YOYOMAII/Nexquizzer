# NexQuizzer

A Learning Management System for GED-style practice and live quiz rooms.

## Features

- Live multiplayer quiz rooms
- Flashcards and daily challenge questions
- Teacher workspaces for class management
- School workspaces for seat management
- Progress tracking and leaderboards
- Invoice-based billing and VIP access tiers

## Getting Started

Visit [nexquizzer.com](https://nexquizzer.com) to create an account and access the platform.
