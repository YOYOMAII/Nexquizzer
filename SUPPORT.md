# Getting help

For help with the NexQuizzer app or your account, email [support@nexquizzer.com](mailto:support@nexquizzer.com).

## Corrections to this repository

This repository contains public information about NexQuizzer. If a statement or link needs correcting, open a GitHub issue using **Public information correction**. Include the affected file or link, what is incorrect, and the expected information. Blank issues are also available.

Keep account details and other private information out of public issues.

## Security reports

Follow [SECURITY.md](SECURITY.md) and report vulnerabilities privately to [yoyo@nexquizzer.com](mailto:yoyo@nexquizzer.com).
